# 複数人でアノテーションする（Tailscale 経由）

離れた場所にいる複数人で分担してアノテーションし、レビューし合い、
そのうちの 1 台で学習するための手順です。

**CVAT を 1 台に集約し、他の人はブラウザでそこへ入ります。**
こうするとファイルの受け渡しが一切なくなり、レビューは CVAT の標準機能で完結します。

```
   ホスト役の PC                        メンバーの PC
 ┌──────────────────┐            ┌──────────────────┐
 │ CVAT（1つだけ）   │◀── Tailscale ──│ ブラウザ          │  アノテーション
 │ :8080            │            │ 自分の Streamlit  │  （必要なら）
 └──────────────────┘            └──────────────────┘
```

> **なぜ集約するのか**
> 各自が `docker compose up -d` すると CVAT のデータベースも各自の中に別々にできます。
> その状態でレビューしようとすると、毎回「エクスポート → 画像ごと相手に渡す →
> 相手がタスクを作り直して取り込む」が必要になり、どれが最新か分からなくなります。

---

## 全体の流れ

| 誰が | 何をするか |
| --- | --- |
| ホスト役（1 人） | Tailscale を入れる → CVAT を共有する → メンバーのアカウントを作る → **通信を CVAT だけに絞る** |
| メンバー | Tailscale を入れる → 招待を受ける → ブラウザで CVAT に入る |
| 学習する人 | 共有 CVAT からまとめて取り込んで学習する |

ホスト役の PC は、作業中つけっぱなしにしておく必要があります。

---

## ホスト役の手順

### 1. Tailscale を入れる

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up          # ブラウザが開くのでログイン（Google / GitHub 等）

tailscale ip -4            # 例: 100.101.102.103 ← この番号を後で使う
                           #    以降の 100.101.102.103 は、すべてこの値に読み替えてください
```

すでに他の用途（リモートデスクトップなど）で使っている場合は、そのままで構いません。
**別のネットワークを作る必要はありません**（下の「すでに Tailscale を使っている場合」を参照）。

### 2. メンバーに CVAT だけを見せる

やり方は 2 通りあります。**すでに個人用途で使っているなら A を強く勧めます。**

#### A. デバイス共有（相手を自分のネットワークに入れない）

[Tailscale の管理画面](https://login.tailscale.com/admin/machines) を開き、
CVAT を動かしている PC の行の `⋯` → **Share…** → 相手のメールアドレスを入れて送ります。

相手には**その 1 台しか見えません**。自分の他の PC やスマホは見えないままです。
相手は自分の Tailscale アカウントのままで構いません（アカウントを共有する必要はありません）。

#### B. 同じネットワークに招待する

管理画面の **Users → Invite users** からメンバーを招待します。
全員が同じネットワークに入るので、**そのままだと互いの PC すべてに到達できます**。
必ず次の 3. を行ってください。

### 3. 通信を CVAT だけに絞る（重要）

**Tailscale の初期設定は「全員が全部に到達できる」です。**
このままだとメンバーがリモートデスクトップ（RDP / VNC）や SSH でも入れてしまいます。

管理画面の **Access controls** を開き、次のように書き換えます。

```jsonc
{
  // CVAT を動かす PC に付ける目印。自分のメールアドレスに置き換える
  "tagOwners": {
    "tag:cvat": ["your-name@example.com"],
  },

  "grants": [
    // 自分は自分の全機器に自由に入れる（今までどおり）
    {
      "src": ["your-name@example.com"],
      "dst": ["*"],
      "ip":  ["*"],
    },
    // メンバーは CVAT の 8080 番だけ。RDP も SSH も届かない
    {
      "src": ["group:annotators"],
      "dst": ["tag:cvat"],
      "ip":  ["tcp:8080"],
    },
  ],

  "groups": {
    "group:annotators": [
      "tanaka@example.com",
      "suzuki@example.com",
    ],
  },
}
```

書いたら、管理画面の **Machines** で CVAT の PC に `tag:cvat` を付けます
（行の `⋯` → *Edit ACL tags…*）。

> **ACL は Tailscale 側で遮断します。**
> 相手の PC のファイアウォール設定に依存しないので、確実です。
> 保存すると即座に反映されます。

### 4. 確認する

メンバー側から次が「繋がる／繋がらない」になっていれば成功です。

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://100.101.102.103:8080/   # 200 になる
nc -zv -w 3 100.101.102.103 3389                                        # 失敗する（RDP）
nc -zv -w 3 100.101.102.103 22                                          # 失敗する（SSH）
```

### 5. CVAT に共有用の URL を教える

`.env` に次を足して、CVAT を再起動します。

```bash
# 100.101.102.103 の部分は自分の tailscale ip -4 の値
CVAT_CSRF_ORIGINS=http://localhost:8080,http://localhost,http://127.0.0.1:8080,http://100.101.102.103:8080
CVAT_UI_URL=http://100.101.102.103:8080
```

```bash
docker compose up -d cvat_server
```

> この設定を入れなくても動く場合がありますが、CVAT が生成するリンクが
> `localhost` のままになるため、入れておくのが確実です。

### 6. メンバーのアカウントを作る

**全員が `admin` を使い回すのはやめてください。**
誰がどのジョブを担当し、誰がレビューしたのかが記録されなくなります。

```bash
docker compose exec cvat_server bash -c \
  "~/manage.py createsuperuser --username tanaka --email tanaka@local.com"
```

人数分だけ繰り返します。パスワードは英大文字・数字・記号を含む 8 文字以上にしてください。

> `createsuperuser` は管理者権限で作られます。権限を分けたい場合は、
> CVAT の管理画面（`http://<IP>:8080/admin`）から後で調整できます。

## メンバーの手順

### 1. Tailscale を入れる

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

Windows / macOS は [公式サイト](https://tailscale.com/download) からアプリを入れてください。

デバイス共有で招待された場合は、届いたメールのリンクを開いて **Accept** します。

### 2. CVAT に入る

ブラウザで `http://100.101.102.103:8080` を開き、
ホスト役から渡されたユーザー名とパスワードでログインします。

**アノテーションするだけなら、ここまでで完了です。**
このリポジトリを clone する必要も、Docker を入れる必要もありません。

### 3.（任意）自分の Streamlit から共有 CVAT を見る

進捗の集計やデータセット生成を自分でも行いたい場合だけ必要です。
このリポジトリをセットアップしたうえで、`.env` に次を足します。

```bash
CVAT_HOST=http://100.101.102.103:8080       # Streamlit が API で使う
CVAT_WEB_HOST=http://100.101.102.103:8080   # サイドバーのリンク先
CVAT_USERNAME=tanaka                     # 自分の CVAT アカウント
CVAT_PASSWORD=自分のパスワード
```

```bash
docker compose up -d streamlit_app
```

自分の PC で CVAT を動かす必要はないので、次のように止めておけます。

```bash
docker compose stop cvat_server cvat_proxy cvat_ui cvat_db cvat_redis \
  cvat_redis_inmem cvat_redis_ondisk cvat_iam_db opa
```

## 作業の進め方

### 分担する

ホスト役が CVAT でタスクを作り、**ジョブに分割して担当者を割り当てます**。

1. タスク作成時に *Segment size*（1 ジョブあたりの画像枚数）を指定する
2. タスクを開くと、ジョブが一覧で出る
3. 各ジョブの *Assignee* に担当者を設定する

**同じジョブを 2 人が同時に開かないでください。**
CVAT はリアルタイム共同編集ではないので、後から保存したほうで上書きされます。
ジョブが分かれていれば同時に作業できます。

### レビューする

ジョブには段階（Stage）があります。

```
annotation（作業中） → validation（レビュー中） → acceptance（確認済み）
```

担当者が終えたら Stage を `validation` に上げ、レビュー担当を Assignee に設定します。
レビューする人は CVAT 上で直接修正でき、**受け渡しは発生しません**。

進捗は Streamlit の「🏷 Step1: アノテーション」タブで見られます。
フレーム数ベースの完了率、state / stage の内訳、担当者別・タスク別の集計が出ます。

### 学習する

学習する人が「📤 Step2: データ取込」タブから共有 CVAT のタスクをエクスポートし、
データセットを作って学習します。**全員ぶんが 1 か所にあるので、集める作業は不要です。**

学習済みモデルを他の人に渡すときは、「📁 データ管理」の
**モデルの持ち出し**（重み＋評価結果の ZIP）を使ってください。

## すでに Tailscale を使っている場合

**リモートデスクトップ用に使っている場合、別のネットワークを作る必要はありません。**

1 台の PC は同時に 1 つの Tailscale ネットワークにしか入れないため、
「個人用」と「チーム用」を分けようとすると切り替えが必要になり、かえって不便です。

代わりに **デバイス共有（上の A）** を使ってください。

- 自分のリモートデスクトップ環境は今までどおり
- メンバーには **CVAT の PC 1 台だけ**が見える
- 自分の他の PC・スマホは見えない

そのうえで **Access controls でポートを 8080 に絞れば**、
共有した PC に対してもリモートデスクトップでは入れなくなります。

### いま入れる操作の確認

```bash
tailscale status          # 見えている機器の一覧
tailscale ip -4           # 自分のアドレス
```

`tailscale status` に相手の機器が出てこなければ、相手からは到達できていません。

## 気をつけること

**Streamlit は 1 人 1 つです。共有しないでください。**
このアプリは学習の進捗などをプロセス全体で共有する変数に持っているため、
2 人が同じ Streamlit を開くと、進捗も停止ボタンも共有されてしまいます。
設定ファイル（プリセット・テーマ・使う機能）も 1 つなので上書きし合います。

**ラベル定義は最初に配ってください。**
「📤 Step2: データ取込」タブ末尾の「🏷️ チーム共通ラベルエクスポート」から
YAML / TXT / CVAT JSON で書き出せます。ラベル名がずれると、
合流したときに別クラスとして学習されます。

**同じ画像を 2 人が別々にアノテーションしないでください。**
合流すると同じ画像が train と val に分かれて入り、**評価が実力より高く出ます**。

**画像は共有 CVAT にアップロードしてください。**
各自の手元にしかない画像があると、学習する人が取り出せません。

**ホスト役の PC を止めると全員が作業できなくなります。**
スリープ設定も確認しておいてください。

## うまくいかないとき

### メンバーから CVAT に繋がらない

```bash
# メンバー側で
tailscale status | grep <ホストの名前>     # 出てこなければ共有・招待ができていない
ping 100.101.102.103                          # 応答があるか
curl -v http://100.101.102.103:8080/          # HTTP で届くか
```

`ping` は通るのに HTTP が届かない場合は、Access controls でポートが塞がれています。
`"ip": ["tcp:8080"]` が入っているか確認してください。

### ログインできる人とできない人がいる

CVAT のアカウントは PC ごとではなく**人ごと**です。
`createsuperuser` を人数分実行したか確認してください。

### ログイン後にエラーが出る／画面が崩れる

`.env` の `CVAT_CSRF_ORIGINS` に、実際にブラウザで開いている URL を含めてください。
含めたら `docker compose up -d cvat_server` で再起動します。

### 自分（ホスト役）のリモートデスクトップが繋がらなくなった

Access controls で自分自身を許可する行が抜けています。

```jsonc
{
  "src": ["your-name@example.com"],
  "dst": ["*"],
  "ip":  ["*"],
},
```

この行が `grants` の中にあるか確認してください。
