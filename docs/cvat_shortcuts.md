# CVAT よく使うショートカット集

CVAT `v2.64.0` の既定キー割り当てをベースに、本パイプライン（bell_pepper 検出の
画像／動画アノテーション）でよく使うものを頻度順にまとめたもの。

> - アプリ内で **`F1`** を押すと現在のショートカット一覧が開く（バージョンに追従した正確な値）。
> - キーは **Settings → Shortcuts** で変更でき、`Restore Defaults` で既定に戻せる。
> - 3D 専用キーは本用途では使わないため末尾に参考掲載。

---

## 1. 最頻出（ナビ・保存・取り消し）

| キー | 動作 |
|---|---|
| `F` | 次のフレームへ |
| `D` | 前のフレームへ |
| `V` | 数フレーム先へ（ステップ送り） |
| `C` | 数フレーム前へ（ステップ戻し） |
| `→` | 次の「オブジェクトがある/フィルタ条件を満たす」フレームを探して移動 |
| `←` | 前の「オブジェクトがある/フィルタ条件を満たす」フレームを探して移動 |
| `Space` | 自動フレーム送りの再生／停止 |
| `` ` `` または `~` | フレーム番号入力にフォーカス（任意フレームへジャンプ） |
| `Ctrl+S` | 作業を保存 |
| `Ctrl+Z` | 直前のオブジェクト操作を取り消し（Undo） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直し（Redo） |
| ホイール押し込みドラッグ | 画像（フレーム）を平行移動（描画中でも可） |

## 2. 描画・作成

| キー | 動作 |
|---|---|
| `N` | 直前と同じ設定で描画を繰り返す（描画開始／確定） |
| `Esc` | 実行中のキャンバス操作をキャンセル |
| `Ctrl`（描画/編集中） | ポリゴン／ポリラインの自動境界スナップの ON/OFF 切替 |

## 3. オブジェクト操作（BBOX）

| キー | 動作 |
|---|---|
| `Ctrl+C` | 選択中オブジェクトをコピー（CVAT内部クリップボード） |
| `Ctrl+V` | コピーしたオブジェクトを貼り付け |
| `Ctrl` を押しながら貼り付け | 連続貼り付けモード（複数個所に貼る） |
| `Ctrl+B` | **選択中オブジェクトを以降のフレームに複製（propagate）** |
| `Ctrl+(0〜9)` | 選択中／次に描くオブジェクトのラベルを切替 |
| `L` | 選択中オブジェクトのロック切替 |
| `T` → `L` | サイドバーの全オブジェクトのロック切替 |
| `H` | 選択中オブジェクトの表示/非表示切替 |
| `T` → `H` | サイドバーの全オブジェクトの表示/非表示切替 |
| `Q` または `/` | 選択中オブジェクトの occluded（隠れ）属性切替 |
| `Del` / `Shift+Del` | 選択中オブジェクトを削除（`Shift` でロック済みも強制削除） |
| `+` / `=` | 重なり順を手前へ（z値を上げる） |
| `-` / `_` | 重なり順を奥へ（z値を下げる） |
| `Tab` | 現フレーム内の次のオブジェクトへ選択移動 |
| `Shift+Tab` | 現フレーム内の前のオブジェクトへ選択移動 |
| 右クリック（形状上） | サイドバーの該当オブジェクト要素を表示 |

## 4. トラック（動画アノテーション時）

| キー | 動作 |
|---|---|
| `M` | 形状のマージ（結合）モードの ON/OFF |
| `Alt+M` | 形状のスプリット（分割）モードの ON/OFF |
| `G` | グループ化モードの ON/OFF |
| `Shift+G` | 選択形状のグループ解除（グループモード中） |
| `K` | アクティブなトラックのキーフレーム属性を切替 |
| `O` | アクティブなトラックの outside（画面外）属性を切替 |
| `R` | アクティブなトラックの次のキーフレームへ |
| `E` | アクティブなトラックの前のキーフレームへ |

## 5. ポリゴン／ポリライン／点の編集

| 操作 | 動作 |
|---|---|
| `Alt+クリック`（点の上で） | その点を削除 |
| `Shift+クリック`（点の上で） | 形状の編集（点の追加・引き直し） |

## 6. 画像操作

| キー | 動作 |
|---|---|
| `Ctrl+R` | 画像を +90° 回転 |
| `Ctrl+Shift+R` | 画像を −90° 回転 |

## 7. 属性アノテーションモード

| キー | 動作 |
|---|---|
| `↑` / `↓` | 次／前の属性へ移動 |
| `Tab` / `Shift+Tab` | 現フレーム内の次／前のアノテーション済みオブジェクトへ |
| `<数字>` | 現在の属性に対応する値を割当 |

## 実践 Tips（このパイプライン向け）

- **前フレームのBBOXを複数まとめてコピーする専用キーは無い**。動画で同じ物体群が続く
  なら **Track（トラック）モードで描く**と、以降フレームへ自動継続する。単発コピーは
  `Ctrl+C`→`Ctrl+V`、1オブジェクトの複製は `Ctrl+B`（propagate）。
- **自動アノテーションと併用すると速い**: CVAT の **Actions → Automatic annotation** で
  本リポジトリの自作モデル（*YOLO11s/YOLO26m BellPepper (custom)*）を各フレームに一括推論
  → 手直しは上記ショートカットで、という流れが効率的。セットアップは
  [`../serverless/README.md`](../serverless/README.md) を参照。
- ラベルが1種類（bell_pepper）なので `Ctrl+0` でラベル固定しておくと描画が速い。
- こまめに `Ctrl+S`。CVAT は自動保存されないタイミングがある。
