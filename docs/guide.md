## このシステムについて

このシステムは **物体検出モデルを自分で作る** ための一連の流れを、ブラウザだけで体験できるように構成しています。

```
① 画像にラベルを付ける（アノテーション）  ← CVAT
       ↓
② データセットを整形する                  ← Streamlit（Step1: データ取込）
       ↓
③ AIモデルを学習させる                    ← YOLO + Streamlit（Step2: モデル学習）
       ↓
④ 学習結果を確認する（推論・評価）        ← FiftyOne + MLflow（Step3: 推論・評価）
```

この 4 ステップが **機械学習プロジェクトの基本サイクル** です。  
何度もデータを追加・修正しながら精度を高めていきます。

## 各ツールの役割

### 📝 CVAT — アノテーションツール

画像に「ここにこのものがある」という情報を付けるツールです。  
バウンディングボックス（四角形）やポリゴン（多角形）でラベルを付けます。

- **ここで学べること**: アノテーション手法 / ラベル設計 / データ品質 / クラス定義
- **アクセス**: http://localhost:8080

> **エクスポート形式について**: このシステムでは CVAT の「CVAT for images 1.1」（XML形式）でエクスポートし、内部で自動的に YOLO 形式に変換します。CVAT 単体で使う場合は「YOLO 1.1」形式で直接エクスポートすることもできます。

### 🚀 YOLO (Ultralytics) — 物体検出モデル

画像の中から物体を高速に検出するディープラーニングモデルです。  
エポック数・バッチサイズ・モデルサイズなど、主要なパラメータを試せます。

- **ここで学べること**: 転移学習 / ハイパーパラメータ / 過学習と汎化 / mAP・Loss
- **公式ドキュメント**: https://docs.ultralytics.com/

### 📊 MLflow — 実験管理

学習のたびにパラメータ・精度・グラフを自動記録するツールです。  
「どの設定が一番良かったか」を後から比較・再現できます。

- **ここで学べること**: 実験の記録 / パラメータ比較 / モデルレジストリ / 再現性
- **アクセス**: http://localhost:5000

### 🔭 FiftyOne — 評価・可視化

推論結果を画像単位でブラウザから確認できるツールです。  
どの画像で間違えたか・どのクラスが苦手かを視覚的に把握できます。

- **ここで学べること**: 推論結果の分析 / エラー分析 / confidence の見方 / データセット探索
- **アクセス**: http://localhost:5151（推論後に自動起動）

## アノテーションのコツ

アノテーション品質はモデル精度に直結します。以下の点を意識すると精度が上がります。

### バウンディングボックスの描き方

| ポイント | 良い例 | 避けるべき例 |
|---|---|---|
| **ぴったり囲む** | 物体の輪郭に沿って最小限の四角形 | 大きめに余白を取りすぎる |
| **一貫性** | 全画像で同じ基準で囲む | 担当者によってサイズがバラバラ |
| **隠れた物体** | 半分隠れていても見えている部分を囲む | 完全に見えているものだけラベルを付ける |
| **小さい物体** | 可能な限り丁寧に囲む | 小さすぎるからと省略する |

### ラベル設計の注意点

- **クラス数は少なめから始める**: 最初は 3〜5 クラス。増やすのは後からでも可能
- **曖昧なクラスは統合する**: 「リンゴ（赤）」「リンゴ（青）」より「リンゴ」1 つにまとめる
- **チーム内でラベルを統一する**: このシステムの「ラベルエクスポート機能」を活用する
- **背景クラスは不要**: YOLO はアノテーションがない領域を自動的に背景として扱う

### データ収集の目安

| クラスあたりの画像数 | 期待できる精度 |
|---|---|
| 50 枚未満 | 動作確認のみ |
| 100〜300 枚 | 基本的な検出が可能 |
| 500 枚以上 | 実用的な精度 |
| 1000 枚以上 | 高精度・汎化性能が向上 |

> 同じ 100 枚でも、**多様な角度・照明・背景**のデータの方が少ない枚数でも高い精度になります。

## 基本概念ガイド

### 🗂️ データの分割（Train / Val）

機械学習では、集めた画像を **学習用（Train）** と **検証用（Val）** の 2 種類に分けて使います。

```
全データ（例: 100 枚）
├─ Train（学習用）: 80 枚  → モデルがこのデータを見て重みを更新する
└─ Val（検証用）:  20 枚  → 学習に使わずに「テスト」として精度を測る
```

- **train loss**: Train データでの誤差。学習が進むと下がっていく
- **val loss**: Val データでの誤差。「本当に汎化できているか」を示す指標
- Val データは学習中に一切使わないため、「外部のテスト」として機能する

> このシステムでは YOLO が自動的に Train/Val 分割を行います。分割比率は `data.yaml` の `train` / `val` パスで制御できます。

### 📐 mAP / Precision / Recall

| 指標 | 意味 | 目安 |
|---|---|---|
| **Precision（適合率）** | 「検出した」中で本当に正しかった割合 | 誤検出を減らしたいときに重視 |
| **Recall（再現率）** | 「本当にある物体」を何割見つけられたか | 見逃しを減らしたいときに重視 |
| **mAP50** | IoU 0.5 での平均適合率。物体検出の総合スコア | 0.5 以上が実用的な目安 |
| **mAP50-95** | IoU 0.5〜0.95 の平均。より厳密な評価 | COCO データセットの標準指標 |

> Precision と Recall はトレードオフの関係です。confidence の閾値を上げると Precision↑・Recall↓、下げると逆になります。

### 🎯 推論パラメータ（conf / iou）

推論時（FiftyOne での評価・推論実行時）に調整できる重要なパラメータです。

| パラメータ | 意味 | デフォルト | 調整の目安 |
|---|---|---|---|
| **conf** | 検出の最低自信度（confidence 閾値） | 0.25 | 誤検出が多い → 上げる（例: 0.4〜0.6）。見逃しが多い → 下げる（例: 0.1〜0.2） |
| **iou** | NMS（重複排除）の IoU 閾値 | 0.7 | 同じ物体に枠が複数出る → 下げる（例: 0.4〜0.5）。近くの別物体を統合してしまう → 上げる |

- **NMS（Non-Maximum Suppression）**: 同じ物体に対して複数の検出枠が出たとき、最も自信度が高いものだけを残す処理
- `conf` と `iou` は学習後のモデルで**再学習なしに調整できる**唯一のパラメータ

### 📦 IoU（Intersection over Union）

検出した領域と正解の領域が「どれだけ重なっているか」を 0〜1 で表す指標です。

```
IoU = 重なり面積 ÷ 合計面積（和集合）
```

- IoU = 1.0 → 完全に一致
- IoU = 0.5 → 半分重なっている
- 一般的に IoU ≥ 0.5 で「正解」とみなす

> バウンディングボックスが少しずれただけで IoU が大きく下がります。アノテーションの丁寧さが精度に直結します。

### 📈 学習グラフの読み方（過学習を見抜く）

学習中に表示されるグラフで確認すべきポイント：

| 状態 | train loss | val loss | 対処 |
|---|---|---|---|
| **正常** | 下がる | 下がる | そのまま継続 |
| **過学習** | 下がる | 上がる（または横ばい） | データ追加・augmentation・early stopping |
| **学習不足** | 高いまま | 高いまま | エポック数増加・学習率調整 |

> mAP50 は val loss と一緒に確認しましょう。val loss が上昇し始めたエポックが「学習のピーク」です。

### 🔄 転移学習

このシステムでは YOLO の **事前学習済み重み（pretrained weights）** を使って学習を始めます。

- YOLO はあらかじめ大量の画像（COCO データセット等）で学習済み
- そこから自分のデータで「追加学習（ファインチューニング）」する
- **ゼロから学習するよりも少ないデータ・短い時間で精度が出やすい**

> モデルサイズ（nano/small/medium/large）は精度と速度のトレードオフです。  
> まず `yolo11n.pt`（nano）で動作確認し、精度が足りなければ大きいモデルを試すのが定石です。

## 学習パラメータの意味

Streamlit の「Step2: モデル学習」タブで設定できる主要パラメータの解説です。

### エポック数（`epochs`）

学習データ全体を何回繰り返して学習するかの回数です。

| 値 | 目安 |
|---|---|
| 10〜30 | 動作確認・プロトタイプ |
| 50〜100 | 通常の学習 |
| 200 以上 | データが少ない場合・精度を追い込む場合 |

> 多すぎると過学習します。val loss のグラフを見て早めに止めるのも有効です（early stopping）。YOLO には自動で止まる `patience` パラメータがあります（下記参照）。

### 自動停止（`patience`）

`patience` は、**精度が改善しないエポックが何回続いたら学習を自動停止するか**を指定します。

- デフォルト: `patience=100`（100 エポック改善がなければ自動停止）
- `epochs=300` に設定しても、精度が頭打ちになった時点で自動停止するため、PCの前で監視し続ける必要はない
- `patience=0` に設定すると自動停止が無効になり、`epochs` 分だけ必ず学習する

> YOLO は内部で `best.pt`（最も val 精度が良かった時点の重み）を自動保存します。学習が早期停止した場合も `best.pt` が最終的な成果物になります。

### バッチサイズ（`batch`）

1 回のパラメータ更新に使う画像枚数です。

- **小さい（8〜16）**: GPU メモリが少ない環境向け。学習が不安定になることも
- **大きい（32〜64）**: 安定した学習・高速。GPU メモリを多く使う
- `-1` を指定すると GPU メモリに合わせて自動調整（AutoBatch）

### 画像サイズ（`imgsz`）

学習時にリサイズする解像度（正方形の 1 辺）です。

| 値 | 用途 |
|---|---|
| 320 | 高速プロトタイプ |
| 640 | 標準（デフォルト） |
| 1280 | 小さい物体・高精度が必要な場合 |

> 大きくするほど精度が上がる傾向がありますが、学習時間と GPU メモリが増加します。

### 学習率（`lr0` / `lrf`）

パラメータを更新する「歩幅」の大きさです。

- `lr0`: 初期学習率（デフォルト 0.01）
- `lrf`: 最終学習率の割合（`lr0 × lrf` が最終値）
- 大きすぎると発散、小さすぎると収束が遅い
- 基本はデフォルトのまま使い、精度が出ない場合に調整

### 重みの選択（`weights`）

学習のベースとなる事前学習済みモデルです。

| モデル | サイズ | 用途 |
|---|---|---|
| `yolo11n.pt` | nano（最小） | 動作確認・リソース制限環境 |
| `yolo11s.pt` | small | 軽量・高速推論が必要な場合 |
| `yolo11m.pt` | medium | バランス型（最初の本番候補） |
| `yolo11l.pt` | large | 高精度・学習時間増 |
| `yolo11x.pt` | xlarge（最大） | 最高精度・GPU が十分な場合 |

## データ拡張（Augmentation）

YOLO は学習時に自動でデータ拡張（augmentation）を適用します。  
少ないデータでも多様なパターンを学習させるための技法です。

### デフォルトで適用される拡張

| 拡張 | 内容 | 効果 |
|---|---|---|
| **フリップ** | 左右・上下反転 | 対称な物体に有効 |
| **モザイク** | 4 枚の画像を組み合わせる | 小さい物体の検出精度向上 |
| **色調変換** | 明度・彩度・色相の変化 | 照明条件の変化に強くなる |
| **スケール変換** | ランダムなズームイン/アウト | サイズのばらつきに対応 |
| **回転・せん断** | 角度・変形 | 傾いた物体に対応 |

### augmentation のチューニング指針

- **室内環境（照明が安定）**: デフォルトで十分なことが多い
- **屋外・自然物**: 色調変換 (`hsv_h`, `hsv_s`, `hsv_v`) を強めに設定
- **方向性がある物体（文字、矢印など）**: `fliplr=0.0` でフリップを無効化
- **データが極端に少ない（50 枚未満）**: `mosaic=1.0`, `mixup=0.1` を試す

> **augmentation をすべて無効にしたい場合**: `mosaic=0.0`, `fliplr=0.0`, `hsv_h=0.0` のように、各パラメータを個別に `0.0` に設定します。Streamlit の学習設定画面では各パラメータのスライダーで直接調整できます。  
> なお、YOLO の `augment=True/False` というパラメータは推論時の **Test-Time Augmentation（TTA）** を制御するものであり、学習時のデータ拡張には影響しません。
